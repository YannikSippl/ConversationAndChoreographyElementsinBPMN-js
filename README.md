# BPMNGEN TryOut

Dieses Projekt ist ein erster Versuch, die **bpmn-js** Bibliothek zu erweitern, um mit **Custom-Elementen** Conversation- und Choreographie-Diagramme zu erstellen.

## Ziel

- Erweiterung von bpmn-js um eigene Modellelemente
- Fokus auf Conversation- und Choreographie-Notation
- Iteratives Vorgehen mit klarer Checkliste

## Roadmap

✅ Checkliste für neue Elemente
- [x] Meta-Model definiert (JSON)
- [x] Renderer erstellt (wie sieht es aus?)
- [x] Rules definiert (wo darf es platziert werden?)
- [x] Palette/Context Pad (wie greift der User drauf zu?)
- [x] Im Modeler registriert (moddleExtensions + additionalModules)
- [ ] Properties Panel (optional, aber empfohlen für Usability)
